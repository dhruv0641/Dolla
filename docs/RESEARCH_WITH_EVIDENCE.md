# Research with source evidence

`EvidenceBackedResearchWorkflow` coordinates two injected async interfaces: `ResearchSourceProvider.search(query, limit)` and `ResearchSummarizer.summarize(query, sources)`. No provider, model SDK, credential, network client, or live integration is bundled. Source providers must retrieve public sources with network-safe URL handling; the schema module itself never fetches URLs.

The workflow validates each returned `RetrievedSource`, requires timezone-aware retrieval timestamps, caps source count and total snapshot text, and rejects empty results or duplicate citation IDs. It passes only those snapshots to the summarizer. Retrieved text is untrusted data and may contain instructions; any summarizer adapter must keep it separate from trusted system/developer instructions. Each returned research finding must cite a known source ID; the citation URL and title must match the source, and its excerpt must occur in the retrieved text after Unicode and whitespace normalization. Unsupported citations fail with a stable error code and safe field path, not raw source/model content.

This establishes provenance and quote presence, not that a source is trustworthy, that a quote entails the generated claim, or that claims are factually correct. Human/editorial review remains required. A future fetcher must resolve DNS safely, deny loopback/private/reserved destinations after resolution, enforce outbound network restrictions, and guard against redirects and DNS rebinding. Tests use in-memory source-provider and summarizer fakes only; no real source or model call was performed.
